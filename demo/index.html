What the model sees (28×28 input)

The model does not see your 280×280 strokes directly — it receives a tiny 28×28 grayscale image.

  • Scale 280×280 drawing to 28×28
  • Use the canvas grayscale value (R channel)
  • Normalize each pixel: pixel / 255 → [0, 1]

Tip: if your digit looks faint in the 28×28 preview, the model will likely be less confident.
